# squirrel-trigger-web

Static legal/marketing pages for **Squirrel Trigger**, served via GitHub Pages
from the root of `main`.

This repo intentionally contains **no game source, no CI secrets, and no
assets** from the `killersquirrel` repo. It is public — everything here is
published.

## Contents

- `index.html` — privacy policy (source of truth: the `privacy-policy`
  document on AGIAAAA-506; do not edit the wording here without updating
  that document first).

More static pages (e.g. terms of service) may be added later as siblings.
